# September 2026 ASAJ rankings in selection comparisons

Both CARIFTA and Goodwill panels now show the official September 29, 2026 Boys 13–14 ranking snapshot where Aidan has an entry. The ranking is labeled **provisional/historical** and is not treated as verified current selection ranking.

CARIFTA 2027: only date-verified LCM swims from July 1, 2026 qualify for time standards; a snapshot top-two position alone does not establish selection priority. Current qualifying-period rankings, eligibility, AQUA points, other swimmers and ASAJ ratification remain required.

Goodwill 2026: the September 29 snapshot is *after* the competition's qualifying period, so it is displayed for historical context only and **cannot** establish 2026 selection. The official 2026 Goodwill criteria and standards remain separate from CARIFTA 2027.

When newer official rankings are available, the builder's `data/rankings.csv` should be updated with verified ASAJ records and an appropriate source date. The current snapshot date is explicitly labeled in the UI and metadata; do not silently present newer data under the September date.
